# Future Feature list (IN ORDER)
1: Make external drivers loadable.
2: Move non-kernel work out of kernel and make it for system calls instead.
3: Add memory management with virtual address spaces, heap allocation, and page protection.
4: Add isolated processes and preemptive multitasking.
5: Improve filesystem and corruption handling.
6: Add FAT-16 alongside the FAT-12 filesystem support (scrapped FAT-32).
7: Improve COMMAND.APP with batch variables, IF, GOTO, SET, PATH, command history, and TAB completion.
8: Improve applications with arguments, exit codes, safer loading, and shared libraries.
9: Add audio support with audio drivers.
10: Add networking support with network drivers.
