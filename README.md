# VSDOS
A 32-Bit DOS-Like OS that's somewhat inspired by Linux. Pretty much, I already disliked Linux but still wanted the cool setup that Linux has (where you can make it into pretty much any OS). So, I made this. It's DOS-like because it's WAY easier to recreate than Windows NT plus the thing i disliked about Linux is how different it is from Windows.

# BUILD TOOLS NEEDED
NASM, LLVM Clang, QEMU.

# HOW TO BUILD
1: Download the project and extract it into a folder.
2: Run build.bat.
